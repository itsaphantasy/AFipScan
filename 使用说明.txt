========================================================
 AFipScan v1.3  CF 优选 IP 测速工具  使用说明
========================================================

【这是什么】
  在你本地电脑上测速，找出对你当前网络最快、且能连上
  你 edgetunnel 项目的 Cloudflare IP，然后一键写入面板。

【三步用法】
  1. 双击 AFipScan.exe
  2. 点【开始测速】-> 约10秒出结果（再点一次可停止）
  3. 点【一键写入】-> 自动写入面板 -> 去 v2rayN 更新订阅

【配置与程序分离】
  所有设置都在同目录的 config.json 里，改配置不用重新打包：
    sni             = edgetunnel 域名(测速握手用)
    panel           = 面板地址
    admin_password  = 面板登录密码
    subscription_url= 订阅链接(双击框内自动复制)
    port_default    = 默认测速端口
    candidate_urls  = 自动拉取的候选IP列表(网址)
    builtin_ips     = 内置兜底候选IP
  用记事本打开 config.json 修改保存即可。
  如果 config.json 被删除，程序会自动生成一份默认的。

【参数说明】(界面里鼠标悬停也有提示)
  端口       : 默认443，可多端口逗号分隔(443,8443,2053,2083,2087,2096)
  测速数量   : 保留前 N 个最快 IP(默认12)
  并发线程   : 同时测多少个 IP(默认24，卡就调小)
  延迟上限   : 只保留低于该延迟的(默认300ms，扫不到调600)

【界面功能】
  - 获取本地IP：判断当前是本地直连(绿)还是开了代理(红)
  - 环境检测  ：一键检查配置/系统代理/公网/本地代理/面板/候选源/防火墙
  - 更多优选IP源：自定义拉取候选IP的网址(每行一个)
  - 右键结果表格 -> 复制优选IP（纯 IP:端口，每行一个）
  - 右键日志窗口 -> 清空日志
  - 双击订阅地址框 -> 复制订阅链接

【注意】
  config.json 里有面板密码，请勿外传。
  本程序未数字签名，换电脑用若提示"未知发布者"，点"仍要运行"。
  开源地址：https://github.com/itsaphantasy/AFipScan
